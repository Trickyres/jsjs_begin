# 地图点位照片

点位照片由 `points-data.js` 的 `image` 字段关联；每个点位展示一张。新增照片建议压缩为 WebP，并提供准确的 `imageAlt` 和 `imageCaption`。网页中的点位卡片可点击照片放大查看。

## 用户提供的实景照片

`fabric-market.webp`、`icbc.webp`、`gotterwell.webp`、`nanpu-metro.webp`、`sinopec.webp`、`toilet.webp`、`workers-gym.webp` 由用户指定的 `多稼周边点位照片` 文件夹选图、缩小并转换为 WebP。原始照片未被改动。其余既有照片沿用原文件。

`需要更新的点位信息` 文件夹中的 12 张实景照已缩小并转换为同目录 WebP，分别对应馨园健身游泳会所、上海阿力烧烤、芳园村酒楼、老城厢汤包馆、一牛火锅、浩丞名烟名酒、康友四季经络足道、小老板海鲜酒家、定制里定制中心、T-ONE 咖啡、凯凯造型及 BK24 光明便利屋。源照片未改动。康友四季原文件名误写为“康康四季”，已按照片招牌及多稼路230号门牌建点；其经纬度暂由地图按地址解析，`x/y` 只作解析失败时的附近备用位置。BK24 照片可见“光明便利屋”招牌及薛家浜路240号门牌，点位名称和地址已据此校正。
